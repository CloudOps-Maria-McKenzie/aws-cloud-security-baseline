# AWS Cloud Security Baseline

## Project Overview

This project demonstrates how to build a secure AWS environment using security best practices, monitoring, logging, and identity management controls.

The goal of this project is to gain hands on experience with cloud security concepts that are commonly used by Cloud Engineers, Cloud Security Engineers, Systems Engineers, and Site Reliability Engineers.

---

## Objectives

- Build a secure AWS environment
- Configure identity and access management
- Enable logging and monitoring
- Detect security findings
- Document remediation activities
- Learn cloud security best practices

---

## Technologies Used

- AWS IAM
- AWS VPC
- Amazon EC2
- AWS CloudTrail
- AWS CloudWatch
- AWS Config
- Amazon GuardDuty
- AWS Security Hub
- IAM Access Analyzer
